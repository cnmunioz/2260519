#Repositorio de ejemplo

Manejo deGit y Git Hub

```	bash
git --version
git config --global user.name "Carolina Muñoz"		--(global a nivel de toda la máquina
git config --global core.editor "code --wait"
git config --global init.defaultBranch main
git config --list (lista de configuraciones)
git add HELP.md
git add mvnv
git add .
git status
git commit -m "primer commit"

git branch -M main  Renombrar rama

git remote add origin https://github.com/cnmunioz/2260519.git

git remote -v     --- Ver cual es el repositorio remoto
git status   --- estado actal del repositorio

```
